# Additional bug audit: CAD/core

These 21 distinct defects were independently reproduced and approved by Astra before product edits. Astra decision IDs are the case IDs below. Each numbered regression in `tests/bug_audit_50_core.test.mjs` failed against its original product implementation, then passed with the corresponding fix. C05 was a duplicate candidate and is excluded from the count.

| Astra decision | Reachable trigger and source | Confirmed defect and fix | Executable regression |
| --- | --- | --- | --- |
| C01 | Sweep/curve pattern along a sharp open polyline; `core/profile_curves.js:pathFrames` | A carried normal parallel to the next tangent produced a zero binormal. Recover an orthogonal normal from the previous binormal. | C01 sharp sweep paths retain orthonormal frames at every station |
| C02 | Enter skipped instances `1 - 3`; `core/pattern_geometry.js:parseSkippedPatternInstances` | Tokenization split a supported range into endpoints. Normalize whitespace inside digit ranges before splitting. | C02 skipped-instance ranges accept whitespace around their hyphen |
| C03 | Up To Face ray first intersects outside a cylinder/cone's trimmed axial range; `core/extrude_extent.js:sampleHitsFace` | Only the nearest infinite-surface root was considered, missing a valid farther root. Test ordered roots against the selected face's trims; preserve the public raw nearest hit. | C03 Up To Face finds the farther cylinder root when the near root is outside the face; also checks cone and raw-hit compatibility |
| C04 | Insert a saved patterned subassembly with document properties; `core/assembly_structure.js:subassemblyComponent` | The embedded snapshot dropped pattern recipes and properties, removing generated occurrences on replay. Deep-copy both authored fields. | C04 inserted subassemblies retain authored patterns and property metadata |
| C06 | Use bounded native topology inside a rotated/translated subassembly; `core/assembly_structure.js:descriptorToParent` | Face geometry moved but its trim AABB remained in child coordinates. Transform all eight corners and reconstruct parent bounds. | C06 nested topology bounds follow the same rigid placement as its face |
| C07 | Enter a huge finite angle equation/dimension; `core/dual.js:wrapTurn`, `sketch_solver.js:wrapAngle`, `cad_mate_model.js:wrapAngle` | Repeated subtraction stopped making floating-point progress and froze the UI. | C10 | Import a hollow X-axis prism that rotates during recognition and falls back to direct geometry; `core/import_normalization.js:normalizeImportedGeometry` | Vertices rotated while normals stayed in source orientation. Rotate normal buffers with the same source frame. | C10 direct fallback keeps rotated mesh normals aligned with its triangles; uses a complete hollow-prism fixture |
| C11 | Move a recorded annular extrude tool or analytic loft; `core/tool_recipe.js:translateToolRecord` | Inner profile points/curves and typed loft section curves stayed behind. | C12 | Move a body containing an authored radial revolve cut/merge; `core/tool_recipe.js:translateToolRecord`, `toolFeatureRecipe` | The host moved while the revolve tool stayed on its old world axis. | C13 | Import different equal-name/equal-size/equal-triangle-count geometry; `core/import_normalization.js:normalizeImportedGeometry` | Metadata-only IDs collided and replaced the earlier project definition. Include canonical vertex/topology content in deterministic identity; honor explicit IDs. | C13 equal-name equal-count imports keep different geometry definitions |
| C14 | Insert Model Items for two separate equal-depth bosses; `core/model_items.js:seen` | Equality of displayed length suppressed independent source dimensions. Keep distinct source identities; deduplicate manual dimensions by their anchors. | C14 Model Items preserves distinct equal-sized feature dimensions |
| C15 | Move an origin-tagged datum or suppress its fixed relation; `core/sketch_origin.js:sketchOriginPoint` | Origin acquisition reused a moved/free datum. Reuse only a physically zero point with active fixation. | C15 origin acquisition refuses moved datums and suppressed fixed relations |
| C16 | Resolve missing offset metadata while another reference plane has an invalid dependency; `core/offset_planes.js:resolveOffsetPlanes` | Failed graph validation still published twin offset recovery. | C17 | Circular/curve feature pattern of a Hole Wizard seed; `core/hole_callout.js:holeCallouts` | Callout quantity counted only linear pattern copies. | C20 | Apply a subsequent cut to a rotated circular/curve pattern copy; `core/cut_scope.js:cutFootprint` | Scope tested the unrotated analytic profile and could skip an intersecting world-space body. | C21 | Replace the consumed profile of a merged extrusion boss; `core/sketch_profile_rebind.js:rebindReplacedSketchProfiles` | Feature IDs updated but the host's recorded merge profile stayed stale. | C22 | Select a tangent chain across a straight line and circular arc; `core/topology_selection.js:edgesAreTangent` | Arc endpoint chords were mistaken for endpoint tangents, rejecting smooth joins and accepting diagonal nonsmooth ones.
