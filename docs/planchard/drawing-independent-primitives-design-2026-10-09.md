# Independent drawing primitives design — 2026-10-09

Confirmed source gap: Drawing controller has notes/dimensions/section/detail but no paper geometry tools. ensureSheetDoc replaces an existing zero-view sheet on every read, so blank annotation-only sheets cannot currently persist. A fresh empty part may enter Drawing mode but receives meaningless default projected views; no real body should be required for drafting exercises.

Proposed narrow generic scope: preserve explicit zero-view sheets; initialize truly empty authoring documents with zero views; persist drawing.primitives as paper-mm line/polyline/rectangle/circle annotations. They are independent of model feature/sketch geometry and sheet view scale. Browser pointer picks create annotations; polyline Enter finishes, Escape cancels; selection double-click opens numeric paper-coordinate/style editor, Delete participates in existing Undo/Redo. Visible dashed/center styles use existing LINE_STYLES; SVG emits the same actual sheet items. Small endpoint/grid snapping and Shift orthogonal placement guide reliable drafting. No dimensioned CAD profiles or source/model injection.

Owner files: js/modeler_drawing.js/controller, js/cad_sheet.js/render+migration, new core/drawing_primitives.js pure validated helpers, focused tests. Narrow js/modeler.js toolbar buttons/hints may be necessary, coordinated with parent. Existing notes, projected views and topology dimensions remain unchanged. Tests will exercise actual pointer/key/edit/delete handlers, native source unchanged, blank-sheet persistence, Undo/Redo, SVG line/circle/closed rectangle/polyline and invalid coordinates. Code readiness is not exercise acceptance; parent actual Chrome authoring/QA remains required.
