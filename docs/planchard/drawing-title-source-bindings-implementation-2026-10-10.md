# Explicit drawing title/number source bindings

Source supplied PDF451/9-17: BATTERY drawing DWG.NO. reads source filename BATTERY; TITLE reads source Description BATTERY, 6-VOLT. Implemented finite app equivalent: native document name is the file-name equivalent; no proprietary `.sldprt`/`.slddrw` identity or suffix stripping is asserted.

## Ordinary controls and persistence

Sheet → Title block now exposes **Title source**: Manual text / Model Description / Model name, and **Drawing number source**: Manual text / Model name (file-name equivalent). Unchosen legacy records show disabled Existing behavior until the user selects a source; their old implicit Description/manual logic remains unchanged. Choosing a link stores `drawing.title.sources.title` or `.number` as description/name/manual. Manual text remains stored independently while linked; switching back restores it. Linked input is disabled and displays the current source value. An explicit Manual Title equal to the model name is now literal, and explicit empty Manual text remains empty through normalization.

Explicit Description with no Description resolves blank; explicit Name without a valid owner/name resolves blank. Invalid explicit source tags fail closed to blank, and malformed preset binding definitions are rejected. No stale manual text, other property, PartNo or inferred shortened name replaces a missing linked value. Existing template/format application guards remain unchanged; immediate selector/history mutation reacquires the normalized live Drawing after Undo capture.

`sheetTitleMeta` resolves separate title/number values. Shared sheet items drive Canvas and SVG; explicit sources are resolved from the current drawing owner, not frozen provider strings. Name and custom-property metadata participate in the actual controller scene cache, so metadata-only rename/Description changes update without changing native geometry. Both native part and assembly owners use the same resolution path. Reusable Sheet Format/Drawing Template captures independent source definitions as `format.titleSources`, never the source BATTERY title/number strings. Fresh template documents read their own owner. Old formats without bindings retain existing document bindings/manual values.
