# Assembly native Drawing entry and first-sheet settings

Parent actual Chrome FLASHLIGHT authoring confirmed three connected blockers: assembly Editor modes were entirely hidden; ribbon Drawing offered legacy settings/preview only; and keyboard7 entered a native sheet whose canvas was still hidden by an assembly-only CSS rule. The initial owned sheet also ignored the previously applied Letter/in/1:4 legacy settings. This fix addresses actual product behavior without authoring source CAD or claiming new browser acceptance.

Assembly Editor modes now expose Model and Drawing while keeping unsupported Sketch/Split hidden. The legacy Assembly drawing dialog retains Apply/Preview/Export and adds **Open native Drawing**, applying the entered settings before entering the interactive sheet. CSS canvas/hint and assembly 3D-host overrides are scoped to assemblies outside Drawing, so the existing native sheet layout can display its Canvas and hide the 3D host.

The new ensureAssemblyDrawingDoc helper seeds only the first missing/malformed native Drawing from drawingSettings: page size/orientation, units/projection/standard, valid positive scale ratio, formatting/display settings and individual title fields. It retains four ordinary initial views. Existing owned Drawing views, annotations, page/title/scale and explicit empty view sets remain authoritative on every later mode entry. Legacy settings, BOM scope, part/component/mate/chain source data remain intact. Blank titles follow the pre-existing ensureSheetDoc name fallback; explicit later title-source controls remain unchanged. Legacy free-text drawing notes are not automatically published as new paper notes.

They cover first-sheet Letter/in/1:4 + actual shared SVG title/page, no source/settings mutation, cold SVG identity, existing authored-sheet preservation despite changed legacy settings, invalid-settings defaults, execution of the actual dialog native-entry callback with Apply-before-mode ordering, and scoped assembly visibility rules. npm run check passes685 modules and1487 assertions. Parent owns actual Chrome reload, visible canvas, source FLASHLIGHT callouts/chains and cold acceptance. No ADVANCE, browser state, source model or Git changes were made by this agent.
