# ANSI hardware for Exercise 8.9

Companion hardware dimensions are unavailable. The editable example uses 5/16-18 UNC hardware. Sizes 1/4-20 and 3/8-16 are also available.

- Type A Narrow washer basic ID, OD and thickness: [Nickel Systems manufacturer's SAE table](https://www.nickel-systems.com/products/washers/sae-uss/). The 5/16 envelope is independently published by [LH Dottie](https://lhdottie.com/pdf/product-specification-sheet/FWS516), referencing ASME B18.21.1-2009.
- Hex machine screw nut across flats and thickness: [American Fastener manufacturer's Square and Hex Machine Screw Nuts table](https://www.americanfastener.com/nuts/). The model uses envelope midpoints; it is not the larger finished-hex-nut family.
- Pan machine screw recessed head diameter/height and recess diameter/depth/width: [American Fastener manufacturer's head table](https://www.americanfastener.com/wp-content/uploads/2020/06/SELF-DRILLING-SCREWS-PAN-HEAD-AMERICAN-FASTENER.pdf). Local source raster: `scratch/planchard/ansi-pan-head-source.png`.

All source dimensions are inches and converted with exactly 25.4 mm/in. Threads are cosmetic Unified 60°, class 2A external / 2B internal. The cross recess is a real native Boolean cut using the table envelope, with simplified straight walls. Head crown, driver taper and detailed thread flanks are representative; this is an assembly example, not a manufacturing-qualified Phillips tool interface. The pan screw is explicitly marked representative in standard-part metadata.
