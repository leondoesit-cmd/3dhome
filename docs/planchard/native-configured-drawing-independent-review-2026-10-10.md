## Accepted bounded mechanism

- Each owner has an isolated WeakMap cache keyed by configuration ID plus source sketch entities/constraints/frame, features/params, history, references/variables/overrides/rollback and table/configuration data. Stale requests are aborted and results only publish when source key/current entry still matches. Eviction/cancel likewise invalidates publication. Snapshot cloning/applyConfiguration/compile/regenerate never writes active source parts/history/configuration. Tests compare the complete source before/after real worker runs.
- Eligible scope is one canonical circular sweep with a matching circular path/design-table source and a valid row/history. Native worker mesh payload must have verifiedSerializedExact, no invalid/approximate flag, finite triangles and exact-native-mesh provenance. Worker results are released after copying independent geometry. Browser-unavailable native-worker fallback cannot fabricate accepted proof; missing serialized proof fails closed.
- Ordinary configured bodies return prepared native triangles only; missing requests start asynchronously, pending/error/unsupported returns empty geometry. UI statuses expose pending/ready/error. Modeler export/preview/print first awaits every named/inherited configuration, rechecks owner/history/view list, invalidates and uses the same drawingSheet provider as Canvas. No parallel sampled export provider is used on the ordinary current O-RING route.
- Source row changes invalidate by complete authored keys; refreshAll/updatePreview, Drawing entry and cache publication invalidate projection scenes. Name/Description changes affect title cache independently. Source keys/rows remain preserved through Undo; a new cold owner must regenerate its own prepared native meshes.
- No per-view topology proof is claimed: ordinary configured topology tools are refused, Model Items/callouts are excluded, host topology is null on mixed named-configured sheets, and export preflight rejects source-bound dimensions until per-view topology exists. This is conservative sheet-level exclusion and can limit unrelated ordinary-view dimensions; it is explicit scope, not false associativity. O-RING preparation has no remaining dimensions/notes, so this restriction does not block its intended witness.

Before correction, `cad_drawings.js` only rejected a missing prepared provider when nativeConfiguredEligibility was true. If a canonical circular-sweep owner had an additional unsupported extrusion, eligibility became false and public `createDrawingSvg` silently fell through to the old sampled configuredBodiesForView torus. Read-only reproduction using current `tests/fixtures/oring_configured_native_source.json`, adding one unsupported extrude and a named Small isometric, returned24332byte SVG instead of refusing unsupported configured geometry. Ordinary modeler preflight already rejects this unsupported source; the actual one-sweep O-RING route is unaffected.

Existing legacy noncanonical fixture behavior remains distinct and tested. Source-bound dimension guards null active topology on named-native export rather than attaching active-row IDs.
