# Bounded genuine drawing Break implementation

Source contract and larger design: `drawing-break-workflow-design-2026-10-10.md`, sourcePDF111/2-25 and494/10-14. Implemented 2026-10-10 as an application capability only; no actual browser authored book artifact, cold Library acceptance, native/STEP acceptance or whole-book closure claimed here.

New `js/core/drawing_break.js` validates an optional existing-view modifier, clips visible/hidden/cut edges and partial circles in original projected centimetres, removes fully omitted circles, retains exact whole circles at each end, maps source coordinates to a shortened presentation with constant paper-mm gap, returns null inside the gap, and emits paired zigzag/wavy boundaries as shared scene items. Original bounds remain available for measurement. Original model/mesh data is unchanged.

`cad_sheet.js` persists the modifier, includes it and scale in projection caching, uses shortened display extents for layout while reading original bounds for automatic dimensions, maps retained anchors for rendering, splits centrelines/marks at the paper gap, bypasses analytic arc reconstruction for Break fragments, and records separate diagnostics for omitted dimension/note anchors. SVG uses the same scene. Invalid saved modifiers produce an explicit diagnostic and no fabricated full projection.

`modeler_drawing.js` provides Break/edit and Remove workflows on the same view, preserves model-coordinate picks, filters hidden snap anchors, rejects geometry picks inside the gap, checks stale form answers, and applies one undo transaction only after successful validation. Actual quick-form select fields use the established `choices` schema. The form accepts original projected boundary coordinates in mm, shows both axis bounds, sets positive printed gap and wave/zigzag style, and pins the current resolved view scale. `modeler.js` exposes the controls and tool help. Crop/Broken-out/Section/Detail exclude incompatible Break combinations.

**Finite scope:** exactly one ordinary principal orthographic edge view, no shaded/crop/section/detail/broken-out/exploded presentation. Form uses numeric boundary coordinates rather than click-drag boundary authoring. Multi-view shared physical-datum shortening is not implemented; the existing-view single-view restriction prevents misleading alignment. This restriction is an app scope choice, not a book rule. Partial circles become 256-sample clipped line fragments; full circles retain analytic representation. Book browser workflows and aligned-view support remain inventory work.
