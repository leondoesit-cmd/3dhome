# רשימת אובייקטי תלת-ממד ומידותיהם

להלן רשימה מפורטת של כל אובייקטי התלת-ממד (המודלים) הקיימים בקטלוג המערכת, מחולקים לפי קטגוריות.

כל המידות מפורטות ב**סנטימטרים (ס"מ)** לפי המבנה: **רוחב (Width) × עומק (Depth) × גובה (Height)**.

## גרסאות עיצוב (Style variants)

לכמעט כל מודל יש רשימת **גרסאות** (`FURN[type].variants`) הנבחרת בפאנל המאפיינים תחת "גרסה":
גימור (צבע/חומר) ולעיתים גם שינוי צורה — למשל `sink` (יחיד / כפול / חזית חשופה / מונח),
`sofa` (כולל פינתית), `bed` (פלטפורמה / אפיריון / מגירות), `toilet` (תלויה), `bathtub` (חופשית),
`shower` (פינתי מעוגל / פתוח), `wardrobe` (הזזה / פתוח), `pendant` ו-`floorLamp` (צורות שונות).
