The browser workflow exposed two editing issues. An existing offset plane's edit form used a retained selected planar face as its default parent, which could silently detach Plane1 from Top Plane; it now keeps the plane's stored parent. The sketch inspector showed the principal **Top** plane for sketches actually attached to Plane1 or Plane2; it now displays the attached reference plane. A dimension-label-only edit invalidated the exact topology cache and temporarily flagged the Dome's loft-face reference as missing; cache signatures now ignore dimension names while still expiring on geometric value changes.
